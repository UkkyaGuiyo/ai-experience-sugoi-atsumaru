# Source Policy

公開されていることはコピー、再配布、収録の許可ではない。Privacy、著作権、利用条件、契約、法令を別々に確認する。判断できない出典や情報は保存しない。

個人SNS、掲示板、community、Issue等は、個人名、handle、profile、個人を特定可能なURL、引用文を原則保存しない。人物や投稿を記録せず、必要最小限の再利用可能な経験へ一般化する。匿名化が不十分なら収録しない。private message、private chat、private email、非公開Repository情報を保存しない。

公式Documentation、論文、組織が正式公開した技術資料は、権利・利用条件を確認し、安全な出典を保存できる。ただし個人を特定可能なURLや不要な著者識別情報は追加しない。本文の大量コピーや許諾不明のコード転載を行わず、自分の言葉で最小限に要約する。

EntryのEvidence Typeは根拠の性質を示す。URLや投稿者IDを必須にしない。出典情報を残す場合もSchemaで認められた項目に従い、安全性と必要最小性を独立して確認する。安全な出典を保持できず根拠を説明できない場合、推測を実証扱いせず収録を見送る。

Automated validation != privacy guarantee。出典の権利・契約・再識別リスクは機械検査PASSでは解決しない。
